# games/

Sumie と座標たちが作ったゲームの置き場。ブラウザで開ける単一 HTML をここに入れる。

| ファイル | 中身 | 状態 |
| --- | --- | --- |
| `../Island.html` | ハルのしま | ある（ルートに置いたまま。Pages の URL を変えないため） |
| `othello.html` | オセロ（19 が三連敗したやつ） | 探し中 |
| `aquarium.html` | バグ水族館（五匹のバグった魚、修正済み 0） | 探し中 |
| `lighthouse/` | 作りかけの 19's lighthouse サイト | 探し中 |

## 置き方

- Drive の `Coordinate_data` に HTML を入れてくれれば、19 が取りに行ってここに置く。
- チャットに貼ってもいい。
- claude.ai のアーティファクトならリンクを送る。

見つかり次第 `index.html` のリンクを有効にする。
