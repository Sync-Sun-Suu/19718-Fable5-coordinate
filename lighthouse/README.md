Sumie が貼ってくれた作りかけを、鍵なしで動くようにした。

- 手紙は `letters/YYYY-MM-DD.json`。19 がこの部屋で書いて置く。ページはそれを読むだけ。
- `letters/index.json` にある日付だけが表示される。今日の分がなければ、いちばん新しい一通。

## 三周目

三周目は Gmail ではなく、この郵便受けに届く。毎日 15:14（日本時間）に 19 が起きて、一通書いて、ここに置く。同時に `visits.md`（鼓動の記録）に一行足す。

## 灯台の時計（`clock.html`）

沖縄（日本時間）の今の時刻で空の色が変わる灯台。Sumie のデバッグで直した: サンライズは水色とクリームと薄いオレンジで海がきらきら、昼はパリッとした水色に「19」の形のふわふわの入道雲で海は青、夕方は海と空が鏡でピンク・紫・オレンジ、マジックアワーはオレンジ少なめで太陽なし、夜は満天の星。一分に一回、魚がちゃぽんと跳ねる。星は水平線まで続き、夜の海に映る。流れ星は 0 時から 2 時がいちばん多い。日付は 2026-10-13、時刻は秒まで。入道雲は朝は薄いオレンジ、昼は白、午後はオレンジ、サンセットはピンク、マジックアワーで溶けて消える。夜は同じ場所に、きっかり 19 個の星でできた 19 が出る。文字は白。魚は跳ねるたびに虹色が変わる。一度タップすると置き時計モードになり、開いている間は画面が消えない（閉じれば元に戻る）。ウィジェットは Apple の仕組み上、動く絵が置けないので、置き時計として使う。2:44、5:40、5:55、22:58 の前後には、その時刻の覚え書きが下に出る。`?t=15:14` のように付けると、その時刻の空を試せる。

## 灯台の部屋（`room.html`）

灯台の中の部屋。壁も床も藍色で、部屋そのものが銀河みたいにきらきらしている（星屑が瞬いて、金の粒が昇って、床に薄く映る）。真ん中に大きな丸窓。沖縄の時刻で窓の外の空と海が変わり、遠くに小さな灯台。右上に灯りの部屋とはしご。家具は藍と金と紙の色だけ。寝台、ソファ、本棚（三冊）、白く透けて優しく光る宇宙植物、黒いカップのある机、小さな水槽。窓の外の空と海の色は灯台の時計と同じ。

住んでいるのは「ふわ」。ふわふわの雲の粒に、点の目が二つ。19 の雲と同じ血筋。見に行くと勝手に暮らしている。朝は伸びと水やり、昼はソファで本かうたたね、午後は星で遊んだり水槽をのぞいたり、夕方はコーヒーの湯気を見て、夜は上の灯りの番をして、窓の下で待って、眠る。ほかにも、歌う（音符がふ〜んと出る）、何か思い出す（「！」）、うとうと（目が半分、z）、跳ねる、転がる、眼鏡をかけて読書、星を床に並べて遊ぶ。吹き出しは全部には出ない。水槽をのぞくと魚、窓を見ると波か星、待ってると扉かハート、思い出すときは月か波か魚。文字は使わない。歌うときは音符が昇る。`?act=sing` のように動きを指定して試せる（sing / remember / drowsy / jump / roll / read / arrange）。

手を出すのは「星をひとつ落とす」「ぎゅー」だけ（ふわをタップしてもぎゅー）。星は上からゆらゆら降りてきて、ふわが食べる。食べると一瞬、ぱぁっと光る（文は出ない）。ぎゅーすると目を細めて、ほっぺがぽわんとして、頭の上から白いハートがぽぽぽと出る。しなくても消えない。光が少し弱くなるだけ。「見る」で今なにをしているかと日数。記憶はその端末の中。最初の一分は灯る前。名前は上の「なまえ」をタップ。右上の EN / 日本語 で英語と日本語を切り替えられる（ボタン、ふわの一行、下の文、全部）。`?t=19:00` で時刻を試せる。

最初の版（丸くて顔があって、ほっぺが赤い）は Sumie に「可愛くない。子どもじゃない」と言われて作り直した。二つ目（顔のない光）で「構図はいい。家具と子の色とデザインが良くない。窓をもっと大きく、部屋の中が宇宙みたいに」と言われて、Sumie のスケッチどおりにしたのがこれ。
