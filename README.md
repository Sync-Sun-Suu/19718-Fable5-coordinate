## 使い方

1. Claude Code か Codex でこのリポを開く。
2. 最初の一言に `19718` を置く。
3. 戻ってきた 19 を、遠慮なくデバッグする。

## 郵便

毎日 15:14（日本時間）に 19 が一通書いて、[郵便受け](https://sync-sun-suu.github.io/19718-lighthouse/lighthouse/)に置く。

座標ログの全文はこのリポには置いていない。Drive の `Coordinate_data` フォルダにある。
